排版与泛光

播放控制

沉浸模式

无 UI 模式隐藏控件、歌曲信息和进度条。横屏可保留歌曲封面。
移动鼠标或轻触屏幕会短暂显示退出按钮，静止后自动消失。

快捷键

空格：播放 / 暂停　← / →：快退 / 快进 5 秒
S：打开设置　L：打开播放列表
F：切换沉浸　Esc：退出沉浸或关闭设置

播放时齿轮自动隐藏。暂停后可再次进入设置，也可以按 S 直接打开。
实际支持的音频编码取决于浏览器。推荐使用新版 Chrome、Edge、Firefox 或 Safari。
